# Парсер тарифов RialCom

Тестовое задание ПАО «Ростелеком». Приложение загружает актуальные тарифы со
[страницы RialCom](https://www.rialcom.ru/internet_tariffs/), приводит данные четырех
таблиц к единому виду и сохраняет результат в Excel.

В файл попадают:

- интернет для многоквартирных домов;
- интернет и интерактивное ТВ для многоквартирных домов;
- интернет для частных домов и коттеджей;
- интернет и интерактивное ТВ для частных домов и коттеджей.

## Установка

Понадобятся Python 3.10 или новее и
[установленный uv](https://docs.astral.sh/uv/getting-started/installation/).

```shell
git clone https://github.com/DeStep3000/Rostelecom-parser.git
cd Rostelecom-parser
uv sync --dev
uv run playwright install chromium
```

Команда одинаково работает в терминале Linux, macOS и Windows PowerShell.
Виртуальное окружение вручную создавать и активировать не нужно: `uv` создаст
`.venv` в каталоге проекта.

## Запуск

```shell
uv run rialcom-parser
```

Готовый документ появится по пути `output/rialcom_tariffs.xlsx`.

Чтобы увидеть действия робота в обычном окне Chromium:

```shell
uv run rialcom-parser --headed
```

Можно указать другое имя файла, адрес страницы и тайм-аут запроса:

```shell
uv run rialcom-parser --output result.xlsx --timeout 30
uv run rialcom-parser --url https://www.rialcom.ru/internet_tariffs/
```

Если браузер в конкретной системе не может восстановить неполную цепочку
сертификатов RialCom, проверку можно отключить только для этого запуска:

```shell
uv run rialcom-parser --ignore-https-errors
```

Этот параметр следует использовать только для известной страницы из задания.

Справка по всем параметрам:

```shell
uv run rialcom-parser --help
```

## Запуск в Docker

Для сборки и запуска достаточно Docker с поддержкой Compose:

```shell
docker compose run --rm parser
```

Excel-файл будет записан в локальную папку `output`. Для повторного запуска после
изменения зависимостей или Dockerfile образ можно пересобрать:

```shell
docker compose build --no-cache
docker compose run --rm parser
```

В Docker основной контейнер подключается по CDP к отдельному headless Chromium.
Локально отдельный сервис не нужен: Playwright запускает установленный браузер
самостоятельно.

CDP-адаптер также подменяет служебный заголовок `Host` на `127.0.0.1:9222`.
Это необходимо, потому что Chromium отклоняет WebSocket-подключения с Docker-именем
сервиса в заголовке `Host`.

## Проверки

```shell
uv run pytest
uv run mypy
uv run ruff check .
uv run ruff format --check .
```

Тесты парсера используют локальную HTML-фикстуру и не обращаются к сайту. Это
позволяет проверять обработку таблиц независимо от доступности RialCom.

## Структура проекта

```text
src/rialcom_parser/
├── client.py       # управление Chromium и действия на странице
├── cdp.py          # подключение к браузеру в Docker
├── parser.py       # разбор четырех групп тарифов
├── exporter.py     # формирование Excel
├── service.py      # общий сценарий работы
└── cli.py          # аргументы командной строки
tests/
├── fixtures/       # локальная копия структуры таблиц
├── test_cdp.py
├── test_client.py
├── test_parser.py
└── test_exporter.py
```

Парсер проверяет наличие нужных разделов, согласованность числа скоростей и цен,
а также соответствие ТВ-пакетов для многоквартирных и частных домов. Если верстка
сайта изменится несовместимым образом, программа выведет описание проблемы и не
создаст файл с неполными данными.

## Формат результата

Excel-документ содержит один лист «Тарифы» и четыре столбца:

| Столбец | Содержимое |
|---|---|
| Название тарифа | Название интернет-тарифа или комбинация ТВ-пакета и скорости |
| Количество каналов | Число каналов для ТВ-тарифов, пустая ячейка для обычного интернета |
| Скорость доступа | Скорость в Мбит/с, переведенная из кбит/с либо взятая из заголовка таблицы |
| Абонентская плата | Плата за расчетный период в рублях |
